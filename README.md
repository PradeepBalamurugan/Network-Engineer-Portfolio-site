## 🛠️ Tech Stack

Built entirely with standard web technologies — **Zero External Frameworks or Bloat**:

- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) with ARIA accessibility.
- **CSS3:** Responsive CSS grid and flexbox, custom design tokens, dark slate / terminal aesthetic, and CSS media queries.
- **Vanilla JavaScript (ES6+):** Sticky navbar, mobile drawer toggle, active link tracking with `IntersectionObserver`, subtle background network node animation canvas, and client-side form validation.

## ⚡ Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PradeepBalamurugan/Network-Engineer-Portfolio-site.git
   cd Network-Engineer-Portfolio-site
   ```

2. **Open in browser:**
   Double-click `index.html` or run:
   ```bash
   # Python HTTP server
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000` in your web browser.
